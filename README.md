## À Propos du Projet

Ce projet est une adaptation web interactive du concept original "[1000 Pompes Pour la Planète](https://vulgarisation.fr/projet/1000_ppp/)" imaginé par `vulgarisation.fr`.

L'objectif est simple : classer l'énergie nécessaire à la réalisation de plusieurs actions.

*A savoir que ce jeu a été créé par une IA*.

---

## Contenu et Ressources

Ce dépôt contient non seulement le code source du jeu web, mais aussi des ressources pour suivre le défi hors-ligne :

### 🃏 Cartes Téléchargeables

Retrouvez les ressources suivantes dans la section [**Releases**](https://github.com/ScorpionSage510/1000pompespourlaplanete/releases/latest) (ou directement pour la [**v1.0.0**](https://github.com/ScorpionSage510/1000pompespourlaplanete/releases/tag/v1.0.0)) :

*   🧠 **Deck Anki (`.apkg`)** : Un paquet contenant les 50 cartes du défi, prêt à être importé dans [Anki](https://apps.ankiweb.net/) pour un suivi et une mémorisation espacée des actions/infos.
*   📄 **PDF** : Un fichier PDF regroupant l'ensemble des 50 cartes, facile à imprimer ou à consulter sur n'importe quel appareil.

## Comment Utiliser

1.  **Jouer en Ligne :** Cliquez sur le [lien du jeu](https://scorpionsage510.github.io/1000pompespourlaplanete/) ci-dessus.
2. **Jouer en local :** Dans `Code`, vous pouvez télécharger le .zip du site, l'extraire et y jouer localement en ouvrant `index.html` sur votre navigateur.  
3.  **Utiliser les Cartes :**
    *   Rendez-vous sur la page [Releases](https://github.com/ScorpionSage510/1000pompespourlaplanete/releases/latest).
    *   Téléchargez le fichier `.apkg` et/ou `.pdf`.
    *   Importez le deck `.apkg` dans votre application Anki ou consultez/imprimez le PDF.
